## Notes

- `src/models/set_tmp.ts` `set_tmp`: the model adds no arithmetic to the kernel's, whose register notes its own (two_nodes_gagge's Notes): `np.where` on `all_valid` is a ternary and `np.around` the library's `round` (ADR 0019, whitelist items 7 and 9), and upstream's `np.asarray` calls have no counterpart, since the model takes scalars (whitelist item 8). On the 1,000 parity cases, the 292 rounded finite `set` values equal upstream's, and 209 of the 281 unrounded finite ones are bit-identical, the others at most 8.4e-14 relative apart; 427 cases are NaN (node v26.8.2). The five extreme `cooling_effect` cases where the library's SET was up to 6.4 °C from upstream's (`.scratch/v2-all-models/evidence/brentq/data/set_dist.out`) now equal upstream's bit for bit with `calculate_ce`.
- `src/models/set_tmp.ts` `set_tmp`: `SETInputs` receives neither `round_output` nor `calculate_ce` (`models/set_tmp.py:101-113`), and `two_nodes_gagge` does not pass `calculate_ce` to `GaggeTwoNodesInputs` (`models/two_nodes_gagge.py:105-120`), so upstream checks neither: `round_output="x"` rounds and `calculate_ce="x"` takes the SET path on 4.7.0; the parse type-checks both (deviation _shared-8). Upstream's signature has no `units`, which `SETInputs` takes with its default, so the inputs have none.
- `src/models/set_tmp.ts` `SET_TMP_INFO`: `body_surface_area` and `p_atm` keep their defaults inline, as upstream writes them in `set_tmp`'s own signature (`models/set_tmp.py:20-21`), as `use_fans_heatwaves`' INFO does; shared-values proposal #48 is not taken here: `cooling_effect.py:16-17` calls its own constants "set_tmp()/two_nodes_gagge() defaults that cooling_effect() relies on", which `src/models/cooling_effect.ts` reads from `TWO_NODES_GAGGE_INFO`, but `set_tmp` passes both values to `two_nodes_gagge` itself and relies on no other model's default. `position` references `BASE_INPUTS_POSITION` (decision 217), and the parse passes `null` and any case through to `two_nodes_gagge`, as upstream's `SETInputs` does (measured: `position=None` and `position="SITTING"` give `24.31490774`, as 'standing' does).
- `src/models/set_tmp.ts` `set_tmp`: the model returns upstream's `SET`, declared in `src/models/two_nodes_gagge.ts`, the first migrated model that returns it (decision 122); `SET_TMP_INFO.outputs` gives its one field, `set`.
- `src/models/set_tmp.ts` `set_tmp`: the `body_surface_area` note's `:py:meth:` reference becomes a code span naming the function (ADR 0025), `body_surface_area`, which the library has in `utilities`, as `two_nodes_gagge`'s does. The rest of the docstring is kept verbatim, the `position` entry, which names two of the three values `choice_field` accepts, and the `body_surface_area` and `p_atm` entries, which end with no "Defaults to" and no full stop, included. The docstring has no entry for `calculate_ce`, so the TSDoc has no `@param inputs.calculate_ce`, as `two_nodes_gagge`'s has none.
