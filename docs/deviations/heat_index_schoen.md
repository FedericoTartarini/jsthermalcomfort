## Notes

- `src/models/heat_index_schoen.ts` `_schoen_heat_index_optimized`: upstream's kernel runs under numba, so its `np.exp` is numba's, where the library's `Math.exp` is V8's own, and `psy_ta_rh`'s dew point carries `dew_point_tmp`'s `np.exp` and `np.log` (ADR 0009; `_shared.md`'s Notes on `dew_point_tmp`). On 100,000 (`tdb`, `rh`) drawn from [-50, 60) °C and [0, 100) %, half of them rounded to one decimal, and 8 chosen points (`rh` 0 and 100, `tdb` -243.12, -50, 0, 60 and 100 °C), the unrounded `hi` equals upstream's on 95,743 of 100,008, with the same 25 NaN positions, and differs by at most 1.8e-14 relative on the others; after `round(hi, 1)` every value equals upstream's, and every `stress_category` equals (numpy 2.5.4 in the parity image, node v26.8.2). In the parity data, 453 of the 489 unrounded cases are bit-identical and all 511 rounded ones equal.
- `src/models/heat_index_schoen.ts` `heat_index_schoen`: upstream's `np.asarray(tdb)` and `np.asarray(rh)` have no counterpart, since the model takes scalars (ADR 0019, whitelist item 8), and `psy_ta_rh(tdb, rh, p_atm=101325)` passes 101325 positionally, the helper's order (item 1). An `rh` of 0 gives a NaN `hi` and no `stress_category`, upstream's NaN, `null` here (decision 310), where `dew_point_tmp` takes `log(0)`, as upstream's does; numpy's `RuntimeWarning`s there have no counterpart (decision 86). An `rh` outside [0, 100] throws `dew_point_tmp`'s `RangeError` from inside `psy_ta_rh` (deviation _shared-57), after the parse, where upstream raises after `HIInputs`, so the order of the checks is upstream's.
- `src/models/heat_index_schoen.ts` `HISchoenInputs`: the type is named after upstream's `HIInputs` (`classes_input.py:443`), which upstream validates the model with (`models/heat_index_schoen.py:55`), with the model's qualifier, since `heat_index_rothfusz`'s type holds `HIInputs` and takes a `limit_inputs` this model's signature lacks (decision 251). The model returns `HI`, which `heat_index_rothfusz.ts` declares and this file imports (decision 122).
