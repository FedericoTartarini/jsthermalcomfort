## Notes

- `src/models/heat_index_rothfusz.ts` `_rothfusz_heat_index_optimized`: upstream's `tdb**2` and `rh**2` run under numba, which lowers a constant integer power to multiplications (`numba/cpython/numbers.py:281-288`, `static_power_impl`, numba 0.68.0), so `x**2` is `x * x` (ADR 0009). It equals `Math.pow(x, 2)` on 2,000,000 random doubles (node v26.8.2), and the unrounded `hi` equals upstream's bit for bit on the 409 such cases of the parity data.
